# Tetris Multiplayer

A modern, real-time multiplayer Tetris app built with **Flutter** and **Firebase**.

## Tech Stack

| Area | Technology |
|---|---|
| Framework | Flutter (iOS & Android) |
| Backend / Auth | Firebase (Auth, Firestore, Realtime DB) |
| Authentication | Google Sign-In via Firebase Auth |
| Multiplayer | Firebase Realtime Database |
| State Management | Riverpod |
| Navigation | GoRouter |
| Audio | flame_audio |
| Game Engine | Flame |

## Getting Started

### Prerequisites

- Flutter SDK ≥ 3.0.0
- Firebase project with Auth, Firestore, and Realtime Database enabled
- Google Sign-In configured in Firebase Auth

### Firebase Setup

1. Create a Firebase project at https://console.firebase.google.com
2. Enable **Google Sign-In** in Authentication → Sign-in method
3. Enable **Firestore** and **Realtime Database**
4. Add Android and iOS apps in Project Settings
5. Run `flutterfire configure` to generate `lib/firebase_options.dart`
6. Replace `android/app/google-services.json` with the real file
7. Replace `ios/Runner/GoogleService-Info.plist` with the real file

### Install & Run

```bash
flutter pub get
flutter run
```

## Security

- Firestore rules are in `firestore.rules` – deploy with `firebase deploy --only firestore:rules`
- Realtime DB rules are in `database.rules.json` – deploy with `firebase deploy --only database`
- Stats (wins, losses, XP) are write-protected – updated only via Cloud Functions
